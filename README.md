# E-Commerce Database System

## 📌 Overview
This project demonstrates a simple E-Commerce database system using SQL and Python.

## 🛠️ Features
- Designed relational database (Users, Products, Orders)
- Performed SQL queries for:
  - Sales analysis
  - Customer insights
  - Product performance

## 💻 Tech Stack
- SQL (MySQL)
- Python

## 📊 Insights Generated
- Total Sales Revenue
- Top Customers
- Product-wise Sales
